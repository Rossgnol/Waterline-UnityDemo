# 吃水线 / Waterline

Unity 6.3 第一人称箱庭探索 Demo。当前最终版本是 Day11 `Day11_TidalRoutes`：玩家修复船坞、取得工具并决定是否准备浮台；注水后下层通路关闭，准备好的浮台打开另一条撤离路线。

## 使用

- Unity：6000.3.23f1
- 当前场景：`Assets/Waterline/Scenes/Day11_TidalRoutes.unity`
- 编辑器打开：双击 `Open-Waterline.cmd`，或在 Unity Hub 添加本目录
- 已有 Windows 试玩版在外层 `Waterline-Windows` 文件夹，双击其中 `Play.cmd`

操作：WASD 移动，鼠标观察，E 交互，Shift 奔跑，Ctrl 蹲行，M 地图，J 日志，Esc 暂停。
